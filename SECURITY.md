# Security Policy

## Supported version

The `main` branch is the supported development version while AuthZGuard is pre-1.0.

## Reporting a vulnerability

Please do not file public issues containing a proof of concept, tokens, target details, or vulnerability evidence. Use GitHub's private vulnerability-reporting channel for this repository when available, or contact the repository owner through the account profile with a concise description, reproduction steps against a local sample, impact, and a proposed fix if known.

The project treats safe defaults, scope enforcement, credential handling, report sanitization, and CI safety as security-sensitive areas.
